A tiny Python program that writes one line of software error copy to `/output/entry.txt`: a single line of at most 200 characters that tells the user the brutal truth about what went wrong and makes them laugh on the way. The line was picked by drafting ten candidate error messages and duelling them pairwise on the bounty judge's own criteria — a true single-line error message, the real failure named in plain words with what to do next, funny on a single read with an image a reader repeats to a colleague, no padding, and copy a real team could ship in a dialog — then defending the winner against three fresh challengers in a revision round. The drafts, counts and duels are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
